## Experiencia con clientes reales

**Malayca** — [sgf-gastos](https://github.com/GuillermoGiles/sgf-gastos): sistema de gestión financiera multi-empresa, con arquitectura multi-tenant y bases de datos aisladas por unidad de negocio. Next.js, Supabase, RLS por instancia.

**Construções do Sul** — [cds-gastos](https://github.com/GuillermoGiles/cds-gastos): aplicación mobile-first para registro y control de gastos operativos en tiempo real. Next.js, Supabase, DolarAPI.

**[b2b-document-translator](https://github.com/GuillermoGiles/b2b-document-translator)** — Traductor serverless de documentos (PDF, DOCX, imágenes) con OCR de alta precisión mediante Gemini 2.5 Flash.
